# Cairn

Cairn is a local-first personal media library and taste-tracking application.

It helps a person keep track of the works they have discovered, wanted,
experienced, owned, and reflected on over time.

## Architecture

Cairn is a single-user, local-first desktop application built with:

- Tauri 2
- React
- TypeScript
- Vite
- Rust
- SQLite

See the project documentation for the complete architecture and development
conventions.
